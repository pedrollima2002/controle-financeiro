    Privacidade e dados

    Este aplicativo foi desenhado para funcionar sem contas, rastreamento ou servidores.

    ✓

    Seus dados financeiros ficam no seu navegador

    Nenhum lançamento é enviado ao GitHub ou a qualquer banco de dados remoto.

    O que não fazemos

    • Sem analytics, pixels ou telemetria
    • Sem anúncios ou cookies de rastreamento
    • Sem integração bancária
    • Sem armazenamento de senhas ou dados completos de cartão

    O que você precisa saber

    • Limpar os dados do navegador pode apagar seus registros.
    • Outro navegador ou dispositivo não recebe os dados automaticamente.
    • O navegador decide se concede armazenamento persistente.
    • Faça backups regulares e guarde-os em local seguro.
